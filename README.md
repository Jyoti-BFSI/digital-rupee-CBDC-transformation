# Digital Rupee (e₹) CBDC Transformation Platform

## Project Overview

This project is a simulated enterprise Digital Rupee (e₹) transformation
reference implementation for a fictional Indian retail bank, ABC Bank.

The objective is to demonstrate how a retail bank could design business,
functional, technology, risk, operational and analytics capabilities around
a CBDC ecosystem.

## Project Role

BFSI / Digital Banking Transformation Consultant

## Key Capabilities

- e₹ Customer Onboarding
- e₹ Wallet Management
- P2P Payments
- P2M Merchant Payments
- Programmable e₹
- Offline Payment Simulation
- Fraud Monitoring
- AML / Transaction Monitoring
- Reconciliation
- Operational Dashboard
- Power BI Analytics
- REST APIs
- Solution Architecture

## Technology Stack

- React
- Python / FastAPI
- PostgreSQL
- Postman
- Power BI
- Docker
- GitHub
- Draw.io
